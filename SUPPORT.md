# Support

Open Phenomena is an early-stage open-source scientific software project.

## Where to ask questions

Use GitHub Issues for reproducible software defects, scientific validation
concerns, documentation problems, and focused feature proposals. Use GitHub
Discussions, when enabled, for general questions, research ideas, possible
collaborations, and roadmap discussion.

## Before opening an issue

Please check the README, relevant documents under `docs/`, existing issues,
current limitations, and whether the behavior reproduces in a clean environment.
Include the following when relevant:

```text
Operating system:
Python version:
Open Phenomena version or commit:
Installation command:
Reproduction command:
Expected result:
Observed result:
Relevant output artifact:
```

## Support expectations

This project is maintained on a best-effort basis. Response times are not
guaranteed. Issues with a complete reproduction, scientific context, units, and
evidence artifacts are more likely to receive a useful response.

## Unsupported use

The project is not currently intended for clinical diagnosis, safety-critical
engineering, production industrial control, claims of validation beyond the
documented evidence, unsupported physical regimes, or confidential data.
