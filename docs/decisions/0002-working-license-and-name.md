# ADR 0002: Working name and license

- Status: proposed
- Date: 2026-07-21

## Proposal

Use **Open Phenomena** as a package/repository working title and Apache-2.0 as a
working permissive license because its explicit patent grant is useful for a
technology-heavy collaborative project.

## Unresolved

The maintainers must confirm naming, trademark risk, copyright ownership, and
whether Apache-2.0, BSD-3-Clause, or a copyleft license best matches project
governance before the first public release. The Python package name may also be
unavailable on public registries.
