(`A=11.608867326767996 m^2`, `V=3.2263413005232877 m^3`), the maximum absolute
differences from five-point central finite differences with `h=10^-4 m` were:

| Derivative | Maximum absolute difference |
|---|---:|
| Area gradient | `1.4418466420806908e-11 m` |
| Volume gradient | `3.4936498138904426e-12 m^2` |

| Surface-energy gradient (`gamma=0.072 N/m`, `m=2`) | `3.3286082223860092e-12 N` |

These finite-difference differences measure agreement between two numerical
evaluations; they are not uncertainty estimates for the continuum physics.

mesh but not yet continuum- or experimentally validated. Infrastructure has no
physical fidelity claim. No **PV** result is newly claimed. Visualization is
absent (**VO** not applicable), and all optimizer/equilibrium capabilities
remain deferred (**SF** with respect to this milestone).
