# v0.2.0 Milestone 3 numerical-verification report

Scope: backend-neutral constrained-solver contracts and the isolated SciPy
`trust-constr` adapter. No capillary-equilibrium validation is claimed.

For the deterministic one-equality quadratic, SciPy 1.18.0 produced:

```text
x                       = (2.220446049250313e-16, 0.9999999999999996)
objective               = 1.0000000000000002
constraint inf norm     = 2.220446049250313e-16
KKT inf norm            = 6.661338147750939e-16
physical multiplier     = 0.9999999999999998
iterations              = 3
```

With objective scale `10` and constraint scale `2`, the same physical
multiplier was restored as `1.0000000000000004` from the dimensionless value
`0.20000000000000007`, verifying the documented scale and sign convention.

For the `10^10`-scale synthetic problem, explicit nondimensionalization reduced
the deterministic iteration count from 16 to 3. The scaled final KKT and
constraint infinity norms were `3.8146972656250006e-16` and
`7.62939453125e-16`, respectively. This is conditioning evidence for the
adapter, not a general performance guarantee.

## Architecture and storage evidence

- Runtime protocol conformance is tested.
- Importing neutral optimization contracts in a fresh process does not load
  SciPy.
- The physical geometry kernel contains no SciPy or optimization import.
- Objective gradients and constraint Jacobians have independent call counters;
  both are exercised in production adapter execution.
- Exact Hessian, Hessian-vector, and explicit BFGS paths are tested.
- Deterministic option ordering, callback diagnostics, evaluation counts, and
  repeated histories are tested.
- Solver specification/result metadata round-trips through the existing
  immutable `Study`/`Run` JSON+NPZ bundle.
- The frozen v0.1 bundle compatibility test remains part of the full suite.

## Scientific boundary

These tests establish code verification for optimization infrastructure. They
do not establish that a discrete capillary minimizer is physically admissible,
mesh-converged, stable, or Young--Laplace consistent. Sphere recovery and all
such evidence belong to later milestones and are intentionally absent.
