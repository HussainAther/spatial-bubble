# v0.1.0-static-sphere

This release is Open Phenomena's first validated, evidence-bearing vertical
slice. It freezes a static spherical soap bubble as an analytic and numerical
reference problem; it is not a dynamic soap-film simulation.

## Scientific scope and validated quantities

The reference uses an outward-oriented sphere of radius 0.01 m, with
`H=+1/R`, pressure jump defined as `p_internal-p_external`, and the
two-interface soap-film relation `delta_p=4 gamma H`. The analytic sphere and
Young--Laplace reference quantities are **PV** within this idealized problem.
The projected triangular surface, mixed-area cotangent mean curvature,
angle-defect Gaussian curvature, and pressure computed from discrete curvature
are **EA** verified against those references.

At refinement level 4 (2,562 vertices and 5,120 faces), the area-weighted L2
mean-curvature error is `2.997414079652756e-4 m^-1`, or
`2.9974140796527564e-6` relative. The area-weighted L2 pressure-jump error is
`3.5968968955667945e-5 Pa`, also `2.9974140796389955e-6` relative. Measured L2
rates over levels 2->3 and 3->4 are 2.2308442003 and 2.3980852365. The
vertex-transitive level-1 mesh is exact to roundoff; its non-asymptotic
transition is retained in the table but excluded from acceptance evidence.

The coherent lossless plane-parallel Fresnel kernel, s/p power reflectance,
equal incoherent unpolarized average, and wavelength broadcasting are verified
as numerical kernels. Applying the local tangent-plane model to a curved film,
using constant real refractive indices, a uniform prescribed thickness, and
the synthetic two-sided illuminant are **EA**. XYZ/sRGB conversion, tone
mapping, PLY/glTF colors, and view recipes are **VO**. No **SF** field is emitted.

## Generated artifacts

`scientific/manifest.json` plus `scientific/arrays.npz` is the authoritative,
restartable scientific bundle. Reproduction also emits JSON/CSV convergence
tables, Markdown evidence reports, a metadata-bearing VTK XML PolyData file,
and visualization-only PLY/glTF views. Large generated outputs are ignored by
Git. The small `tests/fixtures/static_sphere_baseline.json` regression fixture
is version-controlled because it fixes scientifically meaningful canonical
metrics without duplicating generated field arrays.

## Reproduction

From a clean checkout with Python 3.11, 3.12, or 3.13:

```bash
./scripts/reproduce_static_sphere.sh
.venv/bin/pytest
.venv/bin/ruff format --check .
.venv/bin/ruff check .
.venv/bin/mypy src
.venv/bin/python -m compileall -q src tests
```

The scientific manifest records the Git revision and dirty state, package and
Python versions, resolved dependency versions, platform, source/configuration
SHA-256 hashes, study parameters, and reproduction command.

## Known limitations and deferred physics

There is no experimental soap-film validation, quantified uncertainty, global
spectral light transport, absorption, roughness, wavelength-dependent material
data, polarization transport, VTKHDF, or external ParaView parser test.
Dependency ranges are not yet represented by a cross-platform lock file.
Python 3.14 is excluded from this release because its site initialization skips
the hidden path file emitted by the current editable-install backend.

This release intentionally does **not** model drainage, surfactant transport,
Marangoni flow, evaporation, moving surfaces, airflow coupling, vibration,
rupture, or disjoining pressure. XR interaction and AI explanation are also
deferred. None of those omissions is approximated procedurally in this release.
